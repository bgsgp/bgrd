# 🎲 丐点名将 v5.2

**智能随机点名器** – Python 核心 + C# 启动器 | 语音播报 · 双主题 · GIF 动画

## 📦 版本说明

本软件采用双组件架构：

* **点名核心 (Python)**：负责抽选逻辑、界面显示、语音播报、主题切换等全部功能。
* **启动器 (C# / .NET)**：提供简洁的启动界面，自动检测环境并启动核心程序，便于多版本管理。

## ⬇️ 下载安装包

请根据使用习惯选择以下任一版本（均支持 Windows 10/11 x64）：

| 安装包                                           | 内容                                                        | 适用场景                               |
| --------------------------------------------- | --------------------------------------------------------- | ---------------------------------- |
| `BeggarsRollCall_v5.2_Core_Setup.exe`         | **Core 安装版** <br>仅包含 Python 核心程序（已打包为独立 exe，无需 Python 环境） | 直接运行点名器，无需额外组件，轻量简洁                |
| `BeggarsRollCall_v5.2_WithLauncher_Setup.exe` | **with launcher 安装版** <br>包含 C# 启动器 + Python 核心程序         | 提供启动器界面，可管理配置、快速访问设置，适合喜欢图形启动菜单的用户 |

> 两个版本的核心功能完全一致，区别仅在于是否附带 C# 启动器。

## 🚀 快速开始

1. 下载并运行对应的安装程序（建议以管理员身份安装）。
2. 安装完成后，从开始菜单或桌面快捷方式启动：
   * **Core 版**：直接运行 `BeggarsRollCall.exe`。
   * **Launcher 版**：运行 `丐点名将启动器.exe`，点击“开始点名”启动核心。
3. 在程序目录下创建 `names.txt`（UTF-8 编码），每行一个姓名。
4. 选择抽选人数，点击“开始抽选”，享受点名乐趣！

## 🎨 主要特性

* 🎤 **智能语音播报**：抽取结果自动朗读，支持开关，多人逐个清晰播报。
* 🌓 **暗夜/亮色主题**：一键切换，保护视力。
* 📁 **名单管理**：仅需 `names.txt`，无需数据库。
* 🎬 **抽选动画**：内置 GIF 动效，抽选过程视觉反馈。
* ⚙️ **设置持久化**：窗口大小、主题、语音状态自动保存。
