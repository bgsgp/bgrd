📌 项目概览

“丐点名将·队列” 是一款轻量级、多级随机点名工具，专为课堂、会议、活动抽选设计。 它支持 多级队列管理（每个队列对应一个独立的名单文件），可随机抽取指定人数， 并具备 语音播报、主题切换、配置持久化 等增强特性。

项目包含两个主要分支：

🐍 Python 主版本（python 分支）
基于 Python + PySide6 构建，跨平台支持（Windows / Linux / macOS），稳定可靠。 采用模块化设计，包含完整的点名功能、主题切换、语音播报、配置持久化等。
🖥️ C# / WPF 延伸版本（csharp 分支）
基于 .NET 10 + C# 14 完全重写，采用 MVVM 架构， 提供更流畅的 UI 交互、自动主题适配、原生语音引擎。此版本是 Python 主版本的功能延伸， 为 Windows 用户提供更现代化、更原生的操作体验。

✨ 功能特性

📂

多级队列管理

启动时自动加载 1.txt 作为第1层，支持通过界面 ➕ 按钮无限添加新队列，每个队列独立绑定名单文件。

🎲

随机抽取

从当前队列中抽取指定人数，结果以大字体居中展示，清晰醒目。

🔊

智能语音播报

基于系统 TTS 引擎，自动朗读被点中姓名，支持一键开关，多人名单逐个清晰播报。

🌓

双主题切换

暗夜 / 亮色模式一键切换，保护视力，适应白天 / 夜晚使用环境。WPF 版本支持自动适配系统主题。

⚙️

配置持久化

队列列表、抽取人数、主题偏好、语音开关等自动保存，下次启动无缝恢复。

🎬

GIF 抽选动画

将 gt4-loading.gif 或 now-loading.gif 放入程序目录，抽选时随机播放，增加趣味性。

📖 使用说明

  1. 下载并安装 对应版本（建议以管理员身份安装）。
  2. 准备名单文件：在 Assets 目录下创建 1.txt（UTF‑8 编码，每行一个姓名）。
    💡 WPF 版本支持多级队列：可放置 1.txt、2.txt…… 或通过界面 ➕ 按钮添加任意队列。
  3. 启动程序，选择队列（如有多个）。
  4. 设置抽取人数（1~999），点击“开始抽选”。
  5. 结果以大字体显示，并自动语音播报（可在设置中关闭）。
  6. 点击右上角 ⚙️ 按钮可切换主题、开关语音。

🎬 自定义动画：将 gt4-loading.gif 或 now-loading.gif 放入程序目录，抽选时会随机播放。

💡 设计理念

丐点名将源于课堂随机提问场景，追求 “简单、快速、有趣”。 无数据库、无复杂配置，一个 txt 文件 + 一个 exe 即可运行， 适合教师、主持人、活动组织者使用。

WPF 版本的推出，旨在为 Windows 用户提供 更原生、更流畅 的桌面体验， 同时保留 Python 主版本的跨平台特性，满足不同用户的需求。
