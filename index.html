🐍 Python 核心

基于 PySide6 构建 GUI，抽选逻辑高效稳定；支持自定义 GIF 动画、主题切换、语音播报。

⚙️ C# 启动器

可选 Launcher 版本，提供简洁启动界面，自动检测环境并引导运行，便于多版本管理。

🎙️ 智能语音

抽取结果自动朗读（支持开关），多人名单逐个清晰播报，告别“只读第一个”的烦恼。

🌓 双主题

暗夜/亮色模式一键切换，保护视力，适应白天/夜晚使用环境。

📦 安装版本

本软件提供两种安装包，均面向 Windows 10/11 x64 系统，核心功能完全一致，区别在于是否附带 C# 启动器。

安装包内容说明适用场景
bgrd_vx.x_Core_Setup.exe Core 安装版
仅包含 Python 核心程序（已打包为独立 exe，无需 Python 环境）		 直接运行点名器，轻量简洁，无额外组件
bgrd_vx.x_WithLauncher_Setup.exe with launcher 安装版
包含 C# 启动器 (.NET 10) + Python 核心程序		 提供启动器界面，可管理配置、快速访问设置，适合喜欢图形启动菜单的用户
⚙️ 系统要求：Windows 10 / 11（64 位）。含启动器版本需额外安装 .NET 运行时。

📐 使用说明

1️⃣ 下载并安装对应版本（建议以管理员身份安装）。
2️⃣ 在程序安装目录（或启动器同目录）下创建 names.txt，UTF-8 编码，每行一个姓名。
3️⃣ 启动程序
4️⃣ 选择抽选人数（1~999），点击“开始抽选”。
5️⃣ 结果以大字体显示，并自动语音播报（可在设置中关闭）。
6️⃣ 点击右上角 ⚙️ 按钮可切换主题、开关语音。

🎨 自定义动画：将 gt4-loading.gif 或 now-loading.gif 放入程序目录，抽选时会随机播放。
